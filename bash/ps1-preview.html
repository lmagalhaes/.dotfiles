Worktree indicator options

All based on V14. Detection: git rev-parse --git-dir ≠ --git-common-dir

A — ⎇ badge after branch
normal repo: ● leandro wy ➜ crew-api  src/models  main* worktree: ● leandro wy ➜ crew-api  src/models  my-feature* ⎇
B — worktree name in path
normal repo: ● leandro wy ➜ crew-api  src/models  main* worktree: ● leandro wy ➜ crew-api (my-feature)  src/models  my-feature*
C — ❯ changes color in worktree
normal repo: ● leandro wy ➜ crew-api  src/models  main* worktree (❯ turns yellow): ● leandro wy ➜ crew-api  src/models  my-feature*
D — swap branch icon ( fork)
normal repo ( branch): ● leandro wy ➜ crew-api  src/models  main* worktree ( fork icon): ● leandro wy ➜ crew-api  src/models  my-feature*
